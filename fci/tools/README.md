# Εργαλεία ορολογίας

Τρία βήματα, με τη σειρά, από τη ρίζα του αποθετηρίου:

    python3 fci/tools/extract-corpus.py   # PDF → corpus/*.txt, με σημάδι σελίδας
    python3 fci/tools/build-terms.py      # → fci/terms-5lang.json
    python3 fci/tools/check-terms.py      # επαληθεύει κάθε παραπομπή

Το `check-terms.py` είναι το σημαντικό. Ελέγχει ότι η φράση που επικαλείται κάθε όρος
**υπάρχει αυτούσια** μέσα στο έγγραφο εκείνης της γλώσσας. Έπιασε 29 λάθη στο πρώτο
πέρασμα — λήμματα γραμμένα αντί για τη γραμμένη μορφή, και τρεις παραπομπές που απλώς
δεν έστεκαν. Βγαίνει με κωδικό 1 αν κάτι δεν βρεθεί, οπότε μπαίνει και σε CI.

Το `look.py` είναι για το χέρι: ψάχνει έναν όρο σε όλα τα σώματα κειμένου και δίνει
σελίδα, άρθρο και συμφραζόμενα.

    python3 fci/tools/look.py 'ferma a vuoto' it
    python3 fci/tools/look.py 'arrêt|Vorstehen' fr de

Θέλει `pypdfium2` (το `pypdf` και το `pdfminer` δεν δουλεύουν σε αυτό το μηχάνημα).
